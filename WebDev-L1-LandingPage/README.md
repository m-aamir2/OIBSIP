# NexaFlow Landing Page

An original SaaS landing page built for the **Oasis Infobyte SIP Internship**.

- **Track:** Web Development and Designing
- **Level:** Level 1
- **Task:** Landing Page

## Overview

NexaFlow is a fictional productivity platform for teams that want a calmer, clearer way to plan work, automate repetitive steps, and understand project progress. This project presents the product through an intentionally designed, responsive landing page with CSS-built dashboard visuals rather than stock imagery.

## Technologies

- HTML5
- CSS3 (custom properties, Grid, Flexbox, transitions, and media queries)

## Features

- Sticky navigation with working section anchors
- Product-focused hero with primary and secondary calls to action
- CSS-only SaaS workspace, analytics, and project-board visuals
- Smart Automation, Real-Time Insights, and Secure & Reliable feature content
- Product explanation, business statistics, final CTA, and complete footer
- Responsive layouts for desktop, tablet, and mobile
- Smooth scrolling and subtle, accessible hover states

## Run locally

1. Open the `WebDev-L1-LandingPage` folder.
2. Double-click `index.html`, or open it with any modern web browser.
3. No build step, server, JavaScript, or external framework is required.
